# NaRye Studios Website Rebuild — Prototype

This is a polished, light/editorial rebuild based on the supplied NaRye Studios website material.

Included:
- Home
- Work / development slate
- Q&A / Journal with category filters
- Gemini Sun Gemini Moon
- About / Iyo Numä
- Contact
- Responsive mobile navigation
- Shared visual system
- Editable `posts.js` content file for adding future Q&A/blog posts

The Q&A section intentionally uses a simple content file so new posts can be added without editing the page HTML.

The build uses the supplied visual references as temporary assets. Replace the files in `assets/` with your final high-resolution artwork when ready.
